# أدواتي — النسخة الأولى

موقع عربي مجاني يحتوي على:
- حاسبة العمر
- الفرق بين تاريخين
- محول عملات (بسعر يدخله المستخدم)
- تحويل الأرقام إلى كلمات
- عداد الكلمات والحروف

## تشغيله
افتح `index.html` في المتصفح.

## النشر المجاني
يمكن رفع الملف إلى خدمة استضافة صفحات ثابتة مثل GitHub Pages أو Cloudflare Pages. لا يحتاج الموقع إلى قاعدة بيانات في هذه النسخة.

## ملاحظات
- محول العملات لا يستخدم أسعاراً حية بعد.
- تحويل الأرقام يغطي الأرقام من 0 إلى 999,999,999.
- هذه نسخة أولى ويمكن تطويرها لاحقاً بإضافة SEO، صفحات منفصلة لكل أداة، أسعار عملات حية، إعلانات، وواجهة أفضل للموبايل.
